## 1.1.0 — work-in-progress checkpoint

Enhanced `ctx_index` tool with proper file indexing:
- Reads and indexes actual file content (not just placeholder)
- Chunks large files with overlap (2000 chars, 200 overlap) for better search coverage
- Supports recursive directory indexing with configurable ignore patterns (node_modules, .git, dist, build, .next, out, coverage, .turbo)
- Filters by text file extensions to avoid binary files (supports 50+ extensions)
- Creates session automatically if not exists
- Added `recursive` boolean parameter to IndexSchema (default: false)
- Added comprehensive tests for file indexing and chunking (2 new tests, 11 total passing)
